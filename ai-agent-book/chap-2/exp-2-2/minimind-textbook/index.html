MiniMind-3

一本按章节推进的教材。你将亲手写出 MiniMind-3 与 MiniMind-3-MoE：从「下一个词是什么」开始，一路写到注意力、键值缓存、旋转位置编码、混合专家，以及预训练和对话微调。

怎么开始

用浏览器打开本页即可阅读。建议按目录顺序往下走，读完一章就在旁边的 Python 文件里把那一章的代码写出来。官方源码当作「答案页」，不要一上来对照着抄完整文件。

这本书在教什么

MiniMind 是一个可以从零训练的超小语言模型项目。当前主线模型是 MiniMind-3（约 6400 万参数的稠密模型）和 MiniMind-3-MoE（约 1.98 亿总参数，每次只激活约 6400 万）。结构向 Qwen3 / Qwen3-MoE 对齐：预归一化、均方根归一化、SwiGLU 前馈、旋转位置编码、分组查询注意力。

你会先建立一个「语言模型到底在算什么」的完整图景，再把图景拆成可以独立写、独立验证的模块。写完 Dense 版之后，只替换前馈层，就能得到 MoE 版。

和官方仓库的关系

本教材依据 jingyaogong/minimind 的 model/model_minimind.py、trainer/ 与 dataset/lm_dataset.py 编写。官方项目使用 Apache 2.0 协议。教材中的讲解是重新组织过的教学文本；关键实现与官方行为对齐，包括键值缓存的拼接维度、分组查询的重复方式、混合专家的负载均衡损失，以及生成循环里「只把新词送进模型」这一步。

真正训练时，把 MiniMind-3 主线数据下载到 exp-2-2/minimind_dataset/（该目录不进 Git）；attention.py 可以当作第 5 章的草稿本。
