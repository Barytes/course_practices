先分清三条动机

动机方法你改的是什么
便宜地适应一个领域，尽量别忘通用能力LoRA在原权重旁加低秩增量，只训练增量
更喜欢某种回答、不喜欢另一种DPO用现成的「更好/更差」对，直接推策略

LoRA：把 ΔW 分解成两个瘦矩阵

W'x = Wx + B(Ax)　　A ∈ Rr×d，B ∈ Rd×r，r ≪ d
A 用高斯初始化，B 用全 0，于是训练第一步 ΔW=0，模型行为与基座相同。

生活比喻

不改教科书正文，只在页边贴两张很瘦的便利贴。训练只写便利贴。写完可以把便利贴誊回正文（W ← W+BA），推理就不再需要 LoRA 模块。

官方只给方阵线性层挂 LoRA（in_features == out_features），主要是 768×768 的 q_proj、o_proj。非方阵的 k_proj（768→384）默认不挂。

和前面章节怎么对上

  • 被挂 LoRA 的仍是第 7 章那些线性层。前向变成「原线性 + 低秩增量」。
  • B 必须零初始化，对应「第一步便利贴是空白的」。A 也零初始化的话，梯度进不了 B，增量永远是 0。

策略优化的统一视角

后面几个算法名字很吵，其实都在优化：期望里有「新策略相对旧策略的概率比 r_t」「这个动作比基线好多少 A_t」，再减去一项 KL，防止跑去很远的奇怪策略。差别只在这几项怎么定义。

  • DPO：数据里每条有 chosen 和 rejected。不训练奖励模型。显存比 PPO 小，但不能在线探索。
  • PPO：在线采样，要同时维护 Actor 与 Critic（价值网络）。
  • GRPO：同一道题生成 N 个回答，用组内平均分当基线，不再需要 Critic。一组分数全相同则梯度≈0。
  • CISPO：被 clip 之后梯度别断——把 r_t 只当作权重去乘 log π。官方是 train_grpo.py 的一个 loss_type。
  • Agentic RL：多轮工具，结束才给分。优化的是一条轨迹，不是单句。

小模型上若用「数学题对错」这种 0/1 奖励，几乎所有采样都是 0 分，策略不更新。官方演示更常用给出连续分数的奖励模型。

后训练会收「对齐税」

优化目标变窄后，模型会更会迎合当前奖励。要工具就用 agent 权重，要闲聊稳健就用 full_sft。

自测

  • LoRA 的 B 为什么必须零初始化？A 也零初始化行不行？
  • GRPO 去掉 Critic 之后，基线从哪里来？一组回答分数相同意味着什么？
  • 为什么说 CISPO 是损失改写，而不是全新的采样流程？
自测答案（先自己想）
  1. B=0 则 ΔW=0，第一步行为等于基座。A 也全 0 时，增量对 A 的梯度过不来（乘的是 0），LoRA 学不动。
  2. 基线是同一道题 N 个回答的平均分。分数全相同则优势全是 0，没有可学的方向。
  3. 采样、组内标准化这些步骤可以仍用 GRPO 的；它只改 clip 之后损失怎么回传到 log π。
