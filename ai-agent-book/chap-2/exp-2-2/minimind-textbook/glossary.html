术语表：把每个词说成人话

后面章节会反复用这些词。这里集中翻译成大白话。看不懂某一章时，先回到这一页查词，再往下读。

怎么用这一页

不需要一次背完。第一次见到生词就来查。每个词只记「它在这台机器里干什么」，不必先啃论文定义。

输入和输出

说法人话
token / 词元模型真正看见的最小碎片。不一定是「一个汉字」或「一个英文单词」。可能是半个字、一个词、一块标点。
词表 / vocab一本编号词典。MiniMind 里一共 6400 个编号，从 0 到 6399。
分词器 / tokenizer把人类的字符串切成词元，再换成编号；生成完再把编号拼回文字列。
BPE一种切词规则：从字节出发，反复把最常见的相邻两块焊成新词。
特殊标记不是普通字，是给模型看的结构标签。例如「这段话开始」「助手开始说话」。
bos / eos / padbos=一句话开头，eos=一句话结束，pad=为了凑齐长度而填的空白编号。

形状：怎么念 [B, T, D]

一个张量就是按格子排好的一堆数字。中括号里的数叫形状，告诉你格子怎么排。

字母英文人话MiniMind-3 常见取值
Bbatch一次并行处理几句话训练时 16 或 32；自己试形状时用 2 就够
T 或 seq_lensequence length一句话有几个词元教学例子用 4～16；训练常用几百
D 或 hiddenhidden size每个词元用几个数字来表示768
Vvocab size词典里有多少个编号6400

朗读练习：[2, 5, 768] 念作「2 句话，每句 5 个词，每个词 768 个数」。后面凡是看到形状，都先这样念一遍。

网络内部

说法人话
嵌入 / embedding一张大表。用词元编号当行号，取出那一行向量。编号 42 没有任何「42 很大」的意思，只是钥匙。
隐藏状态某个位置上那串正在被加工的数字。形状通常是 [B, T, 768]。
线性层 / Linear对每个词各自做一次「乘一张可学习的表，得到另一串数字」。句子长度不变。
权重 / 参数那些可学习的数字。训练就是改这些数字，让猜词更准。
logits还没变成概率的原始打分。词表里每个候选都有一个分数。
softmax把一串分数变成一串加起来等于 1 的权重（或概率）。谁分数高，谁权重大。
交叉熵一种打分方式：正确那个词的概率越低，惩罚越大。
残差子层算完之后，把原始输入再加回去。像留一条「原路」，信息不容易走丢。
归一化把一串数字的整体大小拉回稳定范围，避免一层层放大后爆炸。
RMSNormMiniMind 用的归一化：不减均值，只按均方根缩放，再乘可学习的系数。
Dropout训练时随机把一些数字变成 0，减少死记硬背。MiniMind-3 默认关掉（系数 0）。

注意力这一族

说法人话
查询 Q当前位置在问：「我要找什么样的信息？」
键 K每个位置的索引标签：「我这份内容适合被怎样检索？」
值 V每个位置真正要提供的内容。
自注意力Q、K、V 都来自同一串输入，只是经过三块不同的线性层。
因果猜位置 t 的下一个词时，不能看 t 后面的词。否则等于考试偷看答案。
掩码 / mask在算权重之前，把不允许看的格子改成负无穷，softmax 之后它们的权重就是 0。
键值缓存 / KV Cache生成时把已经算过的 K、V 存下来，新词到来时不必把整段历史重算一遍。
多头把 768 维切成好几份，每份独立做一套注意力，再拼回去。像几个人同时从不同角度读同一句话。
GQA / 分组查询查询头比较多，键值头比较少。几个人共用同一本索引，省缓存。
RoPE / 旋转位置编码不把「第几个词」直接加到输入上，而是把 Q 和 K 按位置旋转。点积里就会自动带上相对距离。
head_dim每个头自己的宽度。MiniMind-3：768 / 8 = 96。

一层网络和两种模型

说法人话
前馈 / FFN / MLP注意力读完上下文之后，每个词自己再做一次非线性思考。位置之间这一步互不观看。
SwiGLU带门控的前馈：一部分数字当开关，一部分当内容，相乘后再压回 768 维。
Decoder-Only只有从左到右写的解码器，没有单独的「先读完整段再翻译」的编码器。
层 / block「归一化→注意力→残差」再「归一化→前馈→残差」。MiniMind 把这一层复制 8 份。
稠密 / Dense每个词都走同一套完整前馈。
MoE / 混合专家前馈复制成好几个专家，每个词只去其中几个。总参数变多，单次计算不必全用。
路由器 / gate一个小线性层，负责给每个词打分：该去哪个专家。

训练和生成

说法人话
预训练在大量普通文本上练「猜下一个词」。
SFT / 监督微调换成「用户问、助手答」这种格式继续猜下一个词，而且通常只在助手要说的那些词上算对错。
标签 / labels每个位置「正确答案是几号」。padding 处写成 -100，表示「这里不算分」。
学习率每次根据对错，把参数往正确方向推多少。太大容易冲过头，太小学得太慢。
温度生成时把分数除以 T。T 小更认死理，T 大更爱瞎碰。
top-k / top-p生成时丢掉太离谱的候选，只从比较靠前的几个里抽。
LoRA不改原权重，在旁边加两块很瘦的矩阵。便宜地适应一个小领域。
