延伸阅读：从 MiniMind 走到 2026 旗舰

本书对齐的是 Qwen3 风格的稠密解码器，外加一个很简单的混合专家。2026 年 9 月的开源旗舰已经换成「线性注意力 + 稀疏注意力 + 多流残差 + 极稀 MoE」。这一页只指路，不另开一门课。

这一页只要记住

先把本书写完。MiniMind 的积木（RMSNorm、GQA、RoPE、QK-Norm、SwiGLU、KV Cache、MoE）仍是后面所有变体的底座。然后按「同一条 MiniMind 路 → 把积木再写一遍 → 对照 2026 旗舰」这个顺序出门。

和本书怎么对上

第 5～9 章的注意力，在旗舰里常常被拆成两路：大多数层改成线性记忆（KDA / Gated DeltaNet），少数层改成压缩或稀疏的全局检索（MLA / DSA / CSA）。第 11 章的残差 x + F(x)，在 DeepSeek V4 和 GLM-5.3-Flash 里扩成多条并行流（mHC）。第 13 章的 4 专家 top-1，在 Kimi K3 里变成 896 专家选 16。名字变了，地图没变。

把现代积木再写一遍

MiniMind 停在 Qwen3 dense + 简单 MoE。下面这些仓库用「从小模型手写」的方式，把 2025–2026 的积木拆开：MLA、MoE 路由、Gated DeltaNet、Gemma 4 的夹心归一化和滑窗。

三家旗舰：官方源码与缩小实现

日期以公开信息为准，整理于 2026-09。

Kimi K3（2026-07-27）

2.8T 总参数、激活约 104B。每块 3 层 KDA 夹 1 层 Gated MLA；深度方向用 Attention Residuals 跨层取信息；宽度方向用 Stable LatentMoE（896 专家选 16）。

入口角色
MoonshotAI/Kimi-K3官方仓。技术报告 arXiv:2607.24653。
MoonshotAI/FlashKDAKDA 的高性能核。生产里真正跑的是这个，不是论文伪代码。
MoonshotAI/MoonEP专家并行。K3 把专家打到 896 之后，通信变成独立问题。
MoonshotAI/Kimi-LinearKDA + Gated MLA 配方的前身，比 K3 小，更好读。
microkimi/microkimiRust 缩小实现，声称与官方 1:1 对齐；带自训的 nanokimi-0.2b。也覆盖 DeepSeek-V4-Flash-0731。
k3_architecture_notes.md按「序列 / 深度 / 宽度」三条轴读报告的笔记。

GLM-5.3-Flash（2026-08-26）

320B 总参数、激活约 18B。45 层里 34 层 KDA、11 层稀疏 MLA/DSA，残差走 4 路 mHC，并带原生视觉。相对 GLM-5.3 全文注意力，官方称注意力计算约降 3×、KV 约降 4.4×。

入口角色
zai-org/GLM-5官方仓与权重入口。
Z.ai 产品说明混合稀疏 + 线性注意力、IndexPool、mHC 的官方表述。
Raschka 结构笔记和 Kimi、DeepSeek 的积木怎么拼在一起。

截至 2026-09，没有找到 GLM-5.3 的 nanoGPT 风格教学实现。要看可运行推理，走官方 README 里的 SGLang / vLLM 配方。

DeepSeek-V4.1-Flash（2026-09-10）

552B backbone。40 层拆成 20 层因果编码器 + 20 层解码器：prefill 激活约 8B，decode 约 16B。注意力是 CSA2（跨层复用 KV 与索引），残差是 Single-Pass mHC，另加 196B 的 Engram 条件记忆。

入口角色
deepseek-ai/DeepSeek-V4.1-Flash官方权重、技术报告、可读的 inference/model.py。
发布说明Causal Encoder–Decoder 在 agent 负载上为什么省 prefill。
deepseek-ai/EngramN-gram 查找当「条件记忆」，和 MoE 的条件计算是两条稀疏轴。
hebo1221/nano-deepseek-v4nanoGPT 风格的 DeepSeek-V4（CSA / HCA / mHC / MTP）。推送到 2026-08-14，还没跟上 V4.1 的 CSA2 与 CED。

建议顺序

  1. 写完第 1～17 章，能 strict=True 加载官方权重。
  2. 用 from-minimind-to-more 把 MiniMind 的算法篇补全（尤其 GRPO 变体）。
  3. 在 Raschka 图鉴里打开 MiniMind 同族的 Qwen3 卡片，再并排打开 Kimi K3、GLM-5.3-Flash、DeepSeek-V4.1-Flash。
  4. 动手的话：线性注意力走 LLMs-from-scratch 的 Qwen3.5 笔记本或 single_letter_transformers；K3 走 microkimi；DeepSeek V4 走 nano-deepseek-v4。

常见卡住

  • 「本书过时了？」——没有。旗舰改的是注意力怎么省 KV、残差怎么分流、专家怎么更稀。归一化、RoPE、因果掩码、下一个词损失，一条都没扔掉。
  • 「我该从哪家官方仓抄作业？」——不要。作业仍然只对 jingyaogong/minimind。这一页是出门地图，不是另一套必须对齐的 API。
  • 「V4.1-Flash 没有独立 GitHub 训练仓？」——对。可读实现在 Hugging Face 仓库的 inference/model.py。
