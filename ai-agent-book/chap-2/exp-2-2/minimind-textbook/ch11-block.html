第三部 · 拼装

第 11 章 · 一层 Transformer

把归一化、注意力、前馈用两次残差串起来，就是 MiniMind 的一层。后面 8 层只是把这一层复制 8 份，每份有自己的权重。

这一章只要记住

一层只有两条支路：x ← x + Attention(RMSNorm(x))，再 x ← x + FeedForward(RMSNorm(x))。形状始终是 [B, T, 768]。残差加的是归一化之前的 x。

一层里其实只有两条支路

x ← x + Attention(RMSNorm(x))
x ← x + FeedForward(RMSNorm(x))
两条都是「先归一化，再子层，再加回没归一化的 x」。

生活比喻

绿色折线是高速公路：原路信息可以直接开到下一层。归一化只发生在岔路入口（注意力、前馈各自的大门），不要把高速公路也改道。

MiniMindBlock。注意力返回的键值缓存要原样传出层外，供生成时下一层、下一步使用。

现在动手 · 写到哪里

文件exp-2-2/minimind3/model/model_minimind.py
符号类 MiniMindBlock；子模块名必须是 self_attn、input_layernorm、post_attention_layernorm、mlp，才能加载官方权重
导入不用跨文件 import。Attention / RMSNorm / FeedForward（MoE 时是 MOEFeedForward）都在本文件。
不要改注意力内部。这一章只负责接线。

代码怎么对上原理

  • residual = hidden_states 写在注意力之前 → 「把高速公路上的原车先记下」。若先写成 norm(x) 再覆盖 x，原路就被剪断。
  • self_attn(input_layernorm(...)) → 第一条公式：先 RMSNorm₁，再注意力。
  • hidden_states + residual → 加回没归一化的 x。
  • 第二条残差直接 x + mlp(norm(x)) → 此时的 x 已经包含注意力残差，高速公路是连着的。
  • return ..., present_key_value → 这一层自己的 K/V。8 层就有 8 份缓存，第 12 章用长度为 8 的列表来装。
  • layer_id 官方接了但层内没用到。保留它是为了和官方构造函数签名一致。

残差加错对象是最常见的 bug

必须把注意力之前的 hidden_states 存进 residual。官方用显式的这一行，请照抄这个习惯。

一层的键值缓存

8 层就有 8 份互不相同的 K、V。生成时必须按层分别存储：进入第 ℓ 层的 past_key_value 只属于第 ℓ 层；该层返回的 present_key_value 写回列表的第 ℓ 格。

自测

  • 为什么注意力和前馈各用一个 RMSNorm，而不是共用一个？
  • 若把第二条残差改成加在「前馈输入」而不是「注意力残差之后的 hidden」，信息流会少哪一段？
  • 稠密改 MoE 时，这一层里需要改 Attention 吗？
自测答案（先自己想）
  1. 两次归一化各自学一套 γ，注意力和前馈需要的尺度可以不同。共用等于强迫两条岔路用同一套音量旋钮。
  2. 注意力的输出无法再经过前馈这条岔路进入下一层的高速公路，等于少了一截「读完再想」。
  3. 不需要。只把 self.mlp 换成 MOEFeedForward。第 1 章的 use_moe 就是这个开关。
