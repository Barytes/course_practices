第 11 章 · 一层 Transformer

把归一化、注意力、前馈用两次残差串起来，就是 MiniMind 的一层。后面 8 层只是把这一层复制 8 份，每份有自己的权重。

一层里其实只有两条支路

不要把一层想成「十几步神秘计算」。预归一化解码器的一层就是：

x ← x + Attention(RMSNorm(x))
x ← x + FeedForward(RMSNorm(x))
两条都是「先归一化，再子层，再加回没归一化的 x」。

形状自始至终是 [B, T, 768]。这就是可以安全堆 8 层的原因：每一层进出尺寸相同。

MiniMindBlock。注意力返回的键值缓存要原样传出层外，供生成时下一层、下一步使用。

现在动手写

layer_id 官方接了但层内没用到。保留这个参数，是为了和官方构造函数签名一致，也方便你以后按层号做调试打印。

残差加错对象是最常见的 bug

必须把注意力之前的 hidden_states 存进 residual。若写成 x = x + attn(norm(x)) 且中间不小心把 x 覆盖成 norm(x)，高速公路就被剪断了。官方用显式的 residual = hidden_states，请照抄这个习惯。

一层的键值缓存

8 层就有 8 份互不相同的 K、V。生成时必须按层分别存储，不能把所有层的缓存混成一套。约定：

  • 进入第 ℓ 层的 past_key_value 只属于第 ℓ 层；
  • 该层返回的 present_key_value 写回列表的第 ℓ 格；
  • 外层模型维护长度为 8 的列表。

第 12 章的 MiniMindModel.forward 就是在做这个循环。
