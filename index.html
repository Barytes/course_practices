从零实现
MiniMind-3

一本按章节推进的白话教材。假设你只会一点 Python，还没熟悉「张量形状」「注意力」这些词。每一章都先讲人话、再用超小数字手算、最后才让你写代码。

这本书在干什么

带你亲手写出一个会「猜下一个词」的小语言模型。不是调别人的 API，是把模型内部每一块积木自己写一遍。

怎么开始

用浏览器打开本页即可阅读。请先读第 0 章、术语表和动手地图，不要直接跳进注意力。读完一章，就按「写到哪里」把代码填进 minimind3/ 对应文件。官方源码是「答案页」，先自己写，再对照。

手机阅读

网页版：barytes.github.io/course_practices。若打不开，到仓库 Settings → Pages 把 Source 设成 gh-pages 分支。Safari / Chrome 打开后，用「添加到主屏幕」可以全屏翻章节。不想开网页就下载 minimind-3.epub，用系统图书、多看或微信读书打开。

这本书在教什么

MiniMind 是一个可以从零训练的超小语言模型。当前主线是两台「机器」：

  • MiniMind-3：大约 6400 万个可学习数字（参数）。每次预测都把这 6400 万个数字全部用上。这叫稠密模型。
  • MiniMind-3-MoE：总共大约 1.98 亿个数字，但每次预测只真正用掉大约 6400 万。多出来的部分是「备用专家」，用到才开工。

结构向 Qwen3 对齐。这些名词现在看不懂没关系，第 1 章会画一张完整地图，后面每一章只填地图上的一个格子。

模型参数量（可学习数字的个数）层数每个词用几个数字表示备注

如果只记一个比喻

语言模型像玩词语接龙：看见已经写出的字，猜下一个最可能是什么。整本书都在把「猜」这件事拆成可以手算、可以写代码的小步骤。

和官方仓库的关系

本教材依据 jingyaogong/minimind 的 model/model_minimind.py、trainer/ 与 dataset/lm_dataset.py 编写。官方项目使用 Apache 2.0 协议。

教材里的文字是重新写过的教学文本，会故意写得比源码啰嗦。关键实现与官方行为对齐，包括：键值缓存往哪一维拼接、分组查询怎么重复、混合专家的负载均衡损失，以及生成时「只把新词送进模型」。

真正训练时，把 MiniMind-3 主线数据下载到 exp-2-2/minimind_dataset/（该目录不进 Git）。第 2.5 章的填空在 exp-2-2/bpe/；attention.py 留给第 5 章注意力。
