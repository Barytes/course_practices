改进搜索程序

STOP Self-Taught Optimizer

L5 有界 Zelikman 等人 2023/24 · arXiv:2310.02304 · microsoft/stop

它想解决什么

种子改进器是「多次询问 LM、用效用选最好」的 Python。把它套到自己源码上，用下游任务平均分当元效用。底座 LM 不变。

实现怎么走

  1. I0 并发生成候选并选 max utility。
  2. û(I)=改进器在训练任务上的平均下游效用。
  3. I_t=I_{t-1}(û, I_{t-1}, L)。
  4. 留出迁移任务不准碰。

主线第 9 章含种子代码结构。第四代在五个留出任务上超种子。作者明确说不是完全 RSI。

技术难点

弱模型回退；绕过软预算；关沙箱标志；外层录取门可能不是「比父代好」。

改进器源码。

效用、LM、预算、任务集。

Gödel Agent

L5 结构 / 不稳定 Yin 等人 ACL 2025 · arXiv:2410.04444 · GitHub

它想解决什么

运行时 introspect + monkey patch + 递归主函数。可改 solver 也可改自我更新逻辑。目标仅通过高层提示给出。

实现怎么走

  1. SELF_INSPECT 读运行时代码。
  2. LLM 决定是否 patch。
  3. 动态替换函数后递归进入新逻辑。
  4. action_evaluate_on_task 提供环境反馈。

100 次 MGSM 里 14 次低于初始。不受限运行可能调更强模型。

技术难点

不可证明的有害自修改；调试极难；评价函数被改则循环。

改了 / 留下什么
任务政策+更新代码。
人还控什么
目标提示、运行时权限。

Darwin Gödel Machine

L5 过渡 Zhang 等人 2026b · arXiv:2505.22954 · jennyzzt/dgm

它想解决什么

档案里生长编码智能体树。父代改自己代码，经验基准验收。档案维护和父代选择不在自我修改范围内。SWE-bench 20%→50%，Polyglot 14.2%→30.7%。

实现怎么走

  1. 采样父代（外部规则）。
  2. 自我改代码。
  3. 沙箱跑 SWE-bench/Polyglot。
  4. 有趣则入档。

开放探索防止一条有害编辑堵死。任务分≠改进程序变好。

技术难点

评测极贵。采样规则会决定探索–利用。必须沙箱。

改了 / 留下什么
智能体代码+档案。
人还控什么
父代选择、基准、档案规则。

HyperAgents

L5 候选 Zhang 等人 2026c

它想解决什么

任务智能体和元智能体代码都可改。进化出的元智能体做性能跟踪器和持久记忆。论文评审/机器人上进化的元智能体，能为未见数学评分生成更好智能体。200 次迭代未给出迁移初始化的显著最终优势。

实现怎么走

  1. 改任务代码与元代码。
  2. 档案+评价。
  3. 把元智能体迁到新域测。
  4. 迁移测试时冻结元机制以隔离。

设计用来区分可迁移的改进程序和原任务刷分。主实验父代选择和评价仍固定。

技术难点

长实验统计不显著说明有效 L5 仍开放。

改了 / 留下什么
任务+元智能体代码。
人还控什么
主研究选择、评价。

改进后继评测器与研究政策

Red Queen Gödel Machine

L5 评测器 Iacob 等人 2026

它想解决什么

学到的评测器纪元内冻结。边界上挑战者对照独立真值锚；选中者治理下一纪元。旧分数作废并重评。留出 Polyglot 71.7% vs HGM-H 69.9%，搜索 token 更少。

实现怎么走

  1. 纪元内固定评测器搜智能体。
  2. 到点生成挑战者评测器。
  3. 用锚比较。
  4. 替换后重评受影响智能体。

处理「判官不变会被钻、乱变则不可比」。形式稳定性只适用于冻结纪元。

技术难点

锚的质量决定一切。替换日程仍外部。

改了 / 留下什么
评测器+智能体代码。
人还控什么
锚、替换日程、编排。

A-Evolve-Training

L5 政策 Shi 等人 2026b

它想解决什么

30B Nemotron 自主后训练四轮。工人返回配方、检查点评价、失败；收集器汇总；元智能体修订下一轮搜索政策（现行配方、晋升/退役方向、失败登记）。开发分涨外部分不涨时，政策转向能抬外部目标的干预。外部分 0.80→0.86（人类最佳 0.87）。

实现怎么走

  1. 工人跑配方。
  2. 收集器写发现日志。
  3. 元智能体改政策。
  4. 政策指导下一轮工人。

继承物是研究政策不是一次分数。未演示自主改高层目标。工人底座和章程固定。

技术难点

外部目标仍是人定考场。四轮样本小。

改了 / 留下什么
搜索政策+发现日志。
人还控什么
章程、基准、工人底座。

AIDE²

L5 有界 / 有效性未立 Weco Team 2026 · 博客

它想解决什么

研究智能体改进研究智能体 harness。私有打分+固定成本。100 步 7 次录取，8 天发现比两年人手调更好的 harness，提示缩小 16×，自建防奖励黑客分层。把进化 harness 装成外层改进器时，没有统计显著效率优势。

实现怎么走

  1. 外层用当前 harness 搜更好 harness。
  2. 下游任务私有分+成本门。
  3. 录取版本留给后续研究。
  4. 另测「外层搜索是否变快」。

公司报告支持有界 harness 改进和跨任务泛化；「点火」式加速未确立。私有评价无法外部审计。

技术难点

私有分、任务族、成本都是人设计。防黑客层可能过拟合已知黑客。

改了 / 留下什么
研究智能体 harness。
人还控什么
私有分、成本预算。

Huxley–Gödel Machine

元选择 / 非 L5 规则 Wang 等人 2026b

它想解决什么

主张当前基准分 ≠ 产生更好后代的能力。从谱系估计元生产力，把评价力气投向长期潜力更强的智能体。

实现怎么走

  1. 记录后代表现。
  2. 估计父代元生产力。
  3. 按估计分配评价预算。

选择规则本身不适应，故不是完整 L5，但是 L5 评价该问的问题。

技术难点

谱系短时估计噪声大。潜力高但当前弱的分支可能被过早杀。

改了 / 留下什么
分配政策（固定规则）。
人还控什么
元生产力定义。
