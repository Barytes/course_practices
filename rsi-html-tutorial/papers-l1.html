FineWeb-Edu

L1 Penedo 等人 2024 · arXiv:2406.17557

它想解决什么

从网页里筛出「有教育味」的预训练数据，因为人无法给万亿词元逐条打分。

实现怎么走

  1. 研究者写 0–5 教育量规，强调中小学知识，避免偏爱 arXiv。
  2. Llama-3-70B-Instruct 给约 46 万页打合成标注（逐条加分提示）。
  3. 在冻结的 Snowflake-arctic-embed-m 上训线性回归头，41 万训练 / 5 万验证，20 epoch，lr 3e-4。
  4. 输出四舍五入到 0–5，阈值 3 留下，验证 F1≈82%。
  5. 小分类器扫全量 FineWeb（约 6 千 H100 小时），得到 1.3T token。

贵模型当老师、便宜模型当工人，是 L1 数据层的标准结构。阈值 2 的版本保留 5.4T，推理分稍弱。主线第 5 章有对照。

技术难点

量规是人写的；分类器继承 Llama 3 偏见；阈值是精度–召回权衡；分类器不会自己改「教育」定义。

改了 / 留下什么
过滤语料 + 分类器权重。
人还控什么
教育定义、提示、阈值、是否用于下游训练。

Google 高保真标签策展

L1 Google Research 2025

它想解决什么

在点击诱饵等任务上，既要大规模初标，又要把专家力气用在真正难的边界样本上。

实现怎么走

  1. 开发者定义任务与决策标准（什么叫 clickbait）。
  2. LLM 按标准给候选打初步标签。
  3. 聚类 + 边界样本选择挑出一小撮信息量大的样本。
  4. 专家只标这一撮，用来校准或训练下游分类器。

人定规则，模型执行初标和找边界。持久产物是校准后的标签集。

技术难点

边界选择算法若不准，专家会浪费在容易题上。LLM 初标的系统偏差可能让整簇都偏。

改了 / 留下什么
高质量标签集。
人还控什么
任务定义、边界选择程序、专家最终权。

Phi-4-reasoning 训练数据选择

L1 Abdin 等人 2025 · arXiv:2504.21318

它想解决什么

为推理模型选出靠近能力边界的样本：太易没信息，太难没信号。

实现怎么走

  1. 研究者规定难度和推理特征，以及评价程序。
  2. LLM 评价管道按这些标准打分。
  3. 留下靠近当前模型能力边界的样本做训练。

和 FineWeb-Edu 同类：标准外部，执行规模化。Phi-4 技术报告（Abdin 等人 2024）还描述了更广的数据政策，那些政策本身仍是研究者定的，所以综述在 L3 节强调「工业自动化 ≠ 经验自治」。

技术难点

「边界」依赖当前模型，但选择程序不会在每一轮后自动改标准——除非人重写。那正是 L3 多出来的一步。

改了 / 留下什么
选中的推理训练数据。
人还控什么
难度定义、评价程序。

NVIDIA NeMo Curator

L1 NVIDIA 2025

它想解决什么

把质量过滤、分类、去重做成可配置模块，按开发者指定的规则和参数执行。

实现怎么走

  1. 用 YAML/API 声明过滤算子链。
  2. 在多 GPU 上跑启发式、分类器和近重复去除。
  3. 输出干净分片给预训练。

标准化之后，同一套菜谱可以反复套到新语料上。这是执行自治，不是策略自治。

技术难点

菜谱错会规模化污染。模块默认阈值往往从别的语料来，换领域要重校准。

改了 / 留下什么
过滤后语料 + 可复用菜谱。
人还控什么
模块选择与参数。

Data-Juicer

L1 Chen 等人 2024 · SIGMOD

它想解决什么

把数据处理抽象成可组合算子，让预定义处理菜谱在大规模语料上执行。

实现怎么走

  1. 算子覆盖语言识别、质量打分、去重、毒性等。
  2. 用户用配方图组合算子。
  3. 分布式执行并缓存中间结果。

和 NeMo Curator 同类，更强调算子组合与可复现实验。

技术难点

组合爆炸：算子顺序会改变分布。缺少对「配方本身」的自动搜索时仍是 L1；若用 AutoML 搜配方且指标固定，可升到 L2。

改了 / 留下什么
处理后语料。
人还控什么
算子配方。

Microsoft SynthLLM

L1 Microsoft Research 2025

它想解决什么

从高质量网页出发，用多阶段程序组织参考概念，再让 LLM 生成多样提示和回答当合成训练样本。

实现怎么走

  1. 选参考网页/概念。
  2. 按预定义多阶段展开概念图。

改了 / 留下什么

人还控什么

SynthAgent

L1 Wang 等人 2026c

它想解决什么

为网页智能体构造任务和互动轨迹监督：探索网页、生成任务、 refinement 轨迹。

实现怎么走

  1. 模型按工作流做网页探索。
  2. 从探索中提出任务。

NVIDIA Nemotron-4 合成监督

L1 NVIDIA 2024

它想解决什么

指令模型生成候选回答，奖励模型按预定义质量维过滤，合成样本用于后续训练。

实现怎么走

  1. 指令模型多样本生成。
  2. 奖励模型按帮助性、诚实、无害等打分。
  3. 保留高分段做 SFT 或偏好对。

质量维是人定的。这是「生成 + 过滤」L1，不是奖励模型自己改质量维（那会靠近评测器演化）。

技术难点

奖励模型盲区会被合成数据放大。质量维之间冲突时，过滤规则必须由人拍板。

改了 / 留下什么
过滤后的合成监督。
人还控什么
质量维、阈值、奖励模型选择。

Yi / Qwen / Phi-4 数据政策

L1 工业 01.AI 2025；Yang 等人 2025；Abdin 等人 2024

它想解决什么

综述把它们的公开报告解读为：数据源准备、打标、选择、构造、混合编排、模型反馈诊断这六项功能上，操作可以很自动，但数据政策、混合策略、训练阶段仍是研究者定义。

实现怎么走

  1. 公开技术报告描述多阶段数据混合。
  2. 部分阶段用模型打分。
  3. 混合比例和阶段顺序由人定实验决定。

这是 L3 节用来划界的材料：不要把「自动过滤」读成「经验自治」。

技术难点

报告往往不公开完整菜谱，外部无法复现决策权到底在哪。

改了 / 留下什么
训练数据混合。
人还控什么
政策与阶段。

DataComp-LM

L1 数据 / L3 对照 Li 等人 2024 · NeurIPS

它想解决什么

在固定的网页池上系统搜索「过滤 + 混合」配方，想找到下一代预训练集。综述在 L3 节引用它：工业界可以把数据选择做成大规模实验，但生成策略、混合配额、训练阶段仍是研究者定义的搜索空间，不是学习者根据自己弱点改课表。

实现怎么走

  1. 从 CommonPool 一类公共池出发。
  2. 按人定的过滤算子和混合比例做消融。
  3. 用下游代理指标选配方。
  4. 留下更好的训练子集给后续预训练。

实现是数据配方的受控搜索。AI/流水线执行过滤，人规定搜什么、用什么代理指标。不要把它读成 L3。

技术难点

代理指标不等于真实下游。过滤会放大池子里已有的偏见。换池子后配方往往要重搜。

改了 / 留下什么
训练子集 + 配方记录。
人还控什么
池子、算子、代理指标。

训练方法层

EDIT

L1 Wu 等人 2026c

它想解决什么

把「找出坏推理步、只改坏的部分」写成两段式训练，改进训练信号而不是让模型自己改训练算法。

实现怎么走

  1. 人规定诊断信号和修订量规。
  2. 系统定位问题步骤。
  3. LLM 按清单只修订受影响部分。
  4. 修订输出用于后续强化学习校准。

诊断–修订被编码成明确程序。AI 执行，人仍定学习目标、反馈信号和更新规则。

技术难点

诊断错会把对的步骤改坏并写进 RL。量规覆盖不全时，一类系统性错误永远修不到。

改了 / 留下什么
修订后的推理轨迹 / 校准后的政策。
人还控什么
诊断标准、RL 配方。

REPO

L1 Zeng 等人 2026

它想解决什么

把多阶段 SOP 和行为约束写进多轮互动训练，用 LLM 评委按人定标准打「有没有按规定走」，再变成奖励。

实现怎么走

  1. 模型按 SOP 走多轮。
  2. LLM 评委按程序性合规打分。

行为程序是人写的。模型学会的是执行 SOP，不是改 SOP。

技术难点

改了 / 留下什么
政策权重。
人还控什么
SOP、评委标准。

Agent-Agnostic C/C++ 性能优化

L1 Lu and Xia 2026

它想解决什么

把完整性能优化控制环放进程序性记忆：分析→热点→候选修改→按工作流验收正确性与性能→失败回滚。

实现怎么走

  1. 运行剖析找热点。
  2. 生成代码修改。
  3. 正确性测试 + 性能对比。
  4. 失败回滚再试下一热点。

控制环是人预先存好的。智能体在具体工作负载上执行。

技术难点

剖析会误导（热点不是根因）。优化可能破坏数值稳定性。未覆盖的工作负载模式没有下一步。

改了 / 留下什么
通过验收的代码改动。
人还控什么
优化工作流、测试。

Meta NCCL Agentic Debugging

L1 Liu 等人 2026a

它想解决什么

把 NCCL watchdog 超时的根因整理成决策树和 runbook，智能体在具体故障上执行：对齐各 rank 证据、追踪集合通信、连接运行时轨迹到代码路径，找最早可行动分叉。

实现怎么走

  1. 收集多 rank 日志。
  2. 按决策树对齐时间线。

技术难点

人还控什么
