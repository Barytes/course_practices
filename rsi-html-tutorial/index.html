人类造的
最后一代 AI

把《The Last AI Built by Humans: Toward Genuine Recursive Self-Improvement》拆成小白也能跟上的课。每一级自治先用人话讲清楚，再把手伸进被引用工作的真实实现：它改了哪一块代码、哪一块权重、哪一块评测，以及卡在哪里。

这本书在干什么

不是教你训练一个新的大模型。是教你看懂一件更底层的事：AI 怎样用经验改自己，并且让「改自己的方法」也一起变强。综述把它叫做递归自我改进，英文缩写 RSI。

怎么开始

用浏览器打开本页即可。请先读第 0 章和术语表。主线按 B0→L5 往上走；第五部把综述引用的每一项工作单独摊开。遇到陌生词，先回术语表，不要硬跳。手机阅读：barytes.github.io/course_practices/rsi。

先记住一个生活例子

想象你在学修自行车。

  • B0：这次车胎漏了，你补上。下次还漏，你得重新想。
  • L1：师傅写好检修清单，你按清单修，并把修好的零件放回工具箱，下次还能用。
  • L2：清单还是师傅定的验收标准，但「先查气门还是先查内胎」由你根据这次失败自己决定。
  • L3：你不但决定怎么修，还决定下一周该练哪种故障——因为你发现自己最不会修变速器。
  • L4：你真正上街修车了。路上遇到的新问题会写成长期规则，影响以后每一位客人。
  • L5：你开始改「学修车的方法」本身：换教材、换考试、换收徒弟的规矩。下一届学徒用的已经是你改过的方法。

整份教程都围着这件事转：改的是这次答案，还是改会留下去、下次还能用的系统？改的是系统，还是改「以后怎么改系统」？

综述到底说了什么

这篇综述来自上海交通大学、清华大学、字节跳动、上海人工智能实验室等机构的研究者。标题里的「人类造的最后一代 AI」不是宣布已经实现，而是一条路线图：如果改进环真的能自己转起来，后人就不必再亲手设计下一代模型的每一步。

它做了四件事：

  1. 用 HCI（剩余空间闭合指数）说明：知识问答已经很强，但写代码、用工具、长期干活还有很大空档。
  2. 把 RSI 定义成一条会留下去、会再进来、能改改进方式的闭环，而不是某一种算法。
  3. 用 B0 到 L5 五级（外加 B0 对照）按「AI 接管了哪一类决定」给现有系统排队。
  4. 把同一套问题放到科学、机器人、软件、医疗、工业现场里对照，并指出八个还没打通的缺口。

请先放下三个误会

误会一：聊天时模型改口，不等于自我改进。那只是这一次对话里的临时修改。
误会二：分数变高，不等于改进器变强。可能只是多试了几次，或钻了评测的空子。
误会三：标题不是成绩单。综述自己强调：真正端到端的 L5 证据仍然很少，而且大多关在固定考场里。
