第 4 章 · 均方根归一化

深层网络里，向量的尺度会一层层漂移。归一化把每个词的那串数字重新拉回稳定的长度，再交给注意力和前馈。MiniMind 用均方根归一化，并且放在子层前面。

这一章只要记住

对每个词自己的 768 个数，算出均方根，再拿原向量去除以它，最后乘一组可学习的缩放系数。目的不是让模型更聪明，而是让 8 层叠起来还能训练得动。

没有它会怎样

注意力里有点积（两个向量对应相乘再相加），前馈里有放大又缩小的线性层。8 层叠起来后，有的位置向量特别大、有的特别小。点积分数会爆炸或消失，训练就不稳。

生活比喻

像音响前面的归一化：有人说话特别大声、有人特别轻。先把音量拉到差不多，后面的均衡器才调得动。归一化不管「这句话说了什么」，只管「音量别跑飞」。

层归一化在做什么，均方根归一化少做了什么

经典层归一化（LayerNorm）对最后一个维度计算均值和方差：先减均值，再除以标准差，再乘可学习的缩放、加可学习的平移。

均方根归一化（RMSNorm）发现：对 Transformer 来说，减均值这一步往往不是必须的。它只做：

RMS(x) = sqrt(mean(x2) + ε)　　y = (x / RMS(x)) × γ
均值在最后一个维度上取。γ（gamma）是和隐藏维度同长的可学习向量，初始化为全 1。没有平移项 β。

人话版三步：

  1. 把这 768 个数每个平方，求平均，再开方。得到一个正数，叫均方根，衡量「这串数字整体有多大」。
  2. 每个数都除以这个均方根。除完之后，这串数字的均方根大约是 1。
  3. 再逐个乘上 γ。γ 一开始全是 1，等于没改；训练后允许某些维度保持得更大或更小。

少一次减均值，计算更便宜，效果在现代解码器里通常不差。Qwen3 和 MiniMind-3 都用它。

超小例子

一个词只有 2 个数：x = [3, 4]。

  • 平方：9 和 16，平均 12.5，开方 ≈ 3.535（这就是 RMS）。
  • 相除：[3/3.535, 4/3.535] ≈ [0.849, 1.131]。
  • 检查：0.849² + 1.131² 再平均再开方，大约是 1。

ε（epsilon，极小的正数，如 1e-6）加在开方里面，防止这串数字全是 0 时除以 0。

为什么是「先归一化再算子层」

有两种摆法：

  • 后归一化：先注意力，再把「输入 + 注意力输出」归一化。早期 Transformer 论文是这样。
  • 预归一化：先对输入归一化，再送进注意力；注意力输出与未经归一化的原始输入相加。

预归一化的残差通道是「干净的高速公路」：原始信号可以一路传到网络深处，梯度更好走。小模型、深一点的模型几乎都改用预归一化。MiniMind 每一层有两次：注意力前一次，前馈前一次；整网输出前再来一次。

预归一化。子层看到的是尺度稳定的向量；残差看到的是原始 x。两条路不要加错对象。

现在动手写

官方把开方倒数写成 torch.rsqrt（算 1/√·，一次完成），并先转成 float 再算，避免半精度下方差过小变 inf。你应按同样顺序写。

现在动手 · 写到哪里

文件exp-2-2/minimind3/norm.py
符号类 RMSNorm；真正算均方根的是 norm，对外入口是 forward
怎么跑python -m minimind3.norm，形状应仍是 [2, 4, 768]，均方根接近 1
对应原理上文「人话版三步」：平方求平均再开方 → 相除 → 乘 γ。ε 防止除以 0。
mean(dim=-1, keepdim=True)
只在最后一维（768）上求平均。keepdim 是为了还能和原来的 x 相乘，形状对得上。
x.float() 再 type_as(x)
用 float32 算稳定的均方根，算完再变回原来的精度（可能是 float16）。
self.weight * output
γ 会广播到每个词上：同一套 768 个系数，每个位置都用。

代码怎么对上原理

  • x.pow(2).mean(dim=-1) → 「把这 768 个数每个平方，求平均」。dim=-1 是每个词自己，不是把一句话的所有词混在一起。
  • torch.rsqrt(... + eps) → 1 / RMS。乘回去等价于「每个数都除以均方根」。
  • self.weight 初始 torch.ones(dim) → γ 一开始全是 1，等于没改；训练后才允许某些维度更大或更小。
  • x.float() 再 type_as(x) → 用更稳的精度算音量，算完再变回原来的数据类型。

ε 取多少

官方配置 rms_norm_eps=1e-6，类的默认参数有的地方写的是 1e-5。真正生效的是配置里传入的值。教学代码请一律从 config.rms_norm_eps 传入，不要混用两个默认。

第 9 章还会把同一个 RMSNorm 用在每个注意力头的 96 维上，那叫查询/键归一化。模块是同一个，只是 dim=head_dim 而不是 dim=hidden_size。

常见卡住

  • 对 [B, T, 768] 在 dim=1（词这一维）上求均值。——错了。每个词自己归一化，应该是最后一维 dim=-1。
  • 残差加的是 norm(x) 而不是 x。——高速公路被剪断。第 11 章会再强调一次。
  • 半精度训练时出现 inf。——漏了 x.float()。

自测

  • 为什么残差加的是原始 x，而不是归一化之后的 x？
  • 若不用 x.float()，在 float16 下可能出现什么数值问题？
  • RMSNorm 没有偏置 β。这意味着它不能平移表示，只能缩放。这对预归一化结构为什么通常够用？
自测答案（先自己想）
  1. 预归一化想留一条「未经处理的原路」给梯度走。如果加回去的是 norm(x)，原路就被改掉了，深层会更难训练。
  2. float16 能表示的最小正数比较粗。均方根过小或平方溢出时，可能得到 inf / nan，后面全军覆没。
  3. 后面的线性层自己带得动平移（乘表就相当于换坐标系）。归一化的任务主要是管尺度；少一个 β，参数更少，也和 Qwen3 对齐。
